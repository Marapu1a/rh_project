# PAIR перед началом переноса на Pons

Статус: резервная интеграция, 30.09.2026. Это не разрешение запуска.

Исходники PAIR остаются на прежних путях: `contracts/InfinityCollector.sol`,
PAIR launch scripts, Infinity BUY/indexer, fixtures и тесты. Не перемещаем их,
чтобы сохранить импорты и воспроизводимость. Общая Promo-логика не архивируется.

[Manifest](manifest.json) содержит HEAD и SHA-256 всех 676 файлов рабочего дерева,
включая незакоммиченные изменения и пользовательские изображения.
[План PAIR](robinhood-launch-plan.json) сохранён отдельно в этом каталоге.
Полный ZIP находится локально в `.local/backups/pair-before-pons-20260930.zip`;
он не попадёт в Git. Проверены CRC и побайтовые SHA-256 всех записей архива.

Для восстановления распаковать ZIP в отдельный каталог и сравнить с текущим кодом.
Не распаковывать поверх новой работы. Возвращение на PAIR требует актуального
source review: прежний KT1 был заблокирован сменой implementation.

Действующий перенос: [Pons migration](../../PONS_MIGRATION.md).
