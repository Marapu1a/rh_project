# Статический review: последние решения и FREE_SHORT

Не запускать тесты/сборки/fork. Пользователь снял потолок Short и принял Monthly75/25:
в75% обязательно один победитель получает весь Current, в25% вся сумма переносится.
Старые cap1000 и личный monthly admission больше не кандидаты первого релиза.

Реализован только независимый FREE_SHORT пакет: config mode, исторический freeShort
на cutoff, сохранение бюджета при restart, отказ при maxBudget != uint256.max,
ожидание недостаточного бюджета. Поздние поступления не переписывают commitment.
Legacy FIXED конфиги не мигрируются автоматически. Public execution остаётся закрытым.

Monthly код пока старый: у владельца запрошено, как entries влияют на выбор внутри75%.
Не подменять это равновероятными кошельками или линейными билетами без решения.
Минимум Current100USDG также ещё не принят. Planning75/25 не является реализацией.

Проверь код FREE_SHORT, историческую границу/restart и честность статусов документации.
